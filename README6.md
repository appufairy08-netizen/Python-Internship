# Text Analysis

## Project Description
->This project is based on beginner-level Python code which analyzes a given text and calculates the number of words, characters, vowels, and repeated words.

## Objective
->To implement and practice basic Python functions and code for text processing and analysis.

## Input Data
->"Python is easy and Python is powerful"

## Functions Used
->len()
->split()
->lower()
->append()

## Features
->Calculates total number of words
->Calculates total number of characters
->Calculates total number of vowels
->Identifies repeated words

## Result
->Total words: 7
->Total characters: 37
->Total vowels: 10
->Repeated words: ['python', 'is']

## How to Run
->Install python and Jupyter notebook
->Run the code from file named Text Analysis.ipynb
