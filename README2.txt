# Student Grade Calculator

## Project Description
->This project is based on beginners level python code which used to calculate the student grades and also use of predefined grading conditions.

## Objective
->To implement and practice basic Conditional Statements and apply them in data analysis problem.

## Input Data
->Enter your marks:58


## Conditional Statements Used
->if()
->else()
->elif()

## Features
->It takes the marks of students.
->Calculates the marks as per the given ranges.
->Gives the grades for students as per their marks.

## Result
->Enter your Marks:58
->Grade D


## How to run
->Install python and jupiter notebook
->Run the code from file named Student_Grade_Calculator.ipynb
