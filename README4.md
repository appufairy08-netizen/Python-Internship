# Sales Data Calculator

## Project Description
->This project is based on beginners level python code which analyzes the sales data and also perform basic functions.

## Objective
->To implement and practice basic Python functions and code for sales data processing and analyzing.

## Input Data
->[1800,2700,5600,850,3750,360]

## Functions Used
->sum()
->len()
->max()
->min()

## Features
->It calculates total number of sales
->Calculates total sales
->Calculates Average sales
->Calculates highest sale
->Calculates lowest sale

## Result
->Total number of sales: 6
->Total Sales: 15060
->Average Sales: 2510.0
->Highest Sale: 5600
->Lowest Sale: 360

->Install python and jupiter notebook
