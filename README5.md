# Number Statistics

## Project Description
->This project is based on beginner-level Python code which identifies even and odd numbers and finds the largest and smallest numbers from a given list.

## Objective
->To implement and practice basic Python loops, conditions, lists, and numerical functions for processing numbers.

## Input Data
->[10, 25, 8, 17, 32, 5, 14, 21]

## Functions Used
->max()
->min()
->append()

## Features
->Identifies even numbers
->Identifies odd numbers
->Finds the largest number
->Finds the smallest number

## Result
->Numbers: [10, 25, 8, 17, 32, 5, 14, 21]
->Even numbers: [10, 8, 32, 14]
->Odd numbers: [25, 17, 5, 21]
->Largest number: 32
->Smallest number: 5

## How to Run
->Install Python and Jupyter Notebook
->Run the code from the Jupyter Notebook file
